# Fonts

`Excalifont-Regular-Latin.woff2` is the Latin subset of Excalifont, the hand-drawn font made by the [Excalidraw](https://github.com/excalidraw/excalidraw) project. It is copied unchanged from the `@excalidraw/excalidraw` npm package, version 0.18.1 (`dist/prod/fonts/Excalifont/`). Excalidraw publishes Excalifont under the SIL Open Font License 1.1; see <https://plus.excalidraw.com/excalifont>.

Characters outside the Latin subset are drawn with the system font.
